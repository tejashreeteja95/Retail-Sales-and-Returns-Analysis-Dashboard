# 📊 Retail Sales and Returns Analysis Dashboard

## 📌 Overview

This project presents a **Power BI dashboard** that analyzes retail sales performance using key metrics and visualizations.
The dashboard helps in understanding **revenue, sales quantity, and return trends** across different product categories.

---

## 🎯 Objectives

* Analyze total sales and returns
* Calculate return rate and average order value (AOV)
* Identify top-performing product categories
* Compare sales vs returns
* Provide interactive filtering for better insights

---

## 📈 Key Performance Indicators (KPIs)

* **Total Returns:** 9.56K
* **Total Quantity:** 7K
* **Return Rate:** 2.7%
* **Total Revenue:** 334K
* **Average Order Value (AOV):** 50.65

---

## 📊 Dashboard Features

### 1. Revenue by Product Category

* Displays top product categories contributing to revenue
* Helps identify best-selling products

### 2. Sales vs Returns Analysis

* Compares total quantity sold vs returned
* Highlights categories with high return rates

### 3. Revenue Distribution (Pie Chart)

* Shows percentage contribution of each product category

### 4. Interactive Slicer

* Allows filtering data by product category
